General

What is Konine?

Konine is an actively maintained PHP 8.4+ HMVC framework. It is the successor to Koseven (which was itself the successor to the defunct Kohana Framework). Koseven was archived on April 14, 2026, and Konine exists to keep the framework running — and moving forward — for the applications that depend on it.

What is the project status?

Konine is actively maintained. Stability for existing applications comes first — PHP compatibility, security patches, and bug fixes always take priority — but the project also accepts feature requests and ships requested enhancements when they are built in a backwards-compatible way. The framework will be maintained until PHP 9 reaches end of life, or until the maintainers are no longer able to continue.

Will it work as a drop-in replacement for Koseven or Kohana?

If you were using Koseven, Konine should be a direct drop-in replacement. If you were using Kohana 3.3.x you may need to make some small changes. Please refer to the upgrading from Kohana section of the documentation.

Why does this project exist?

Kohana 3.3.x was used in many live projects, and the original team stopped development. On Feb 4, 2017, "Shadowhand" announced the final retirement — "Kohana is DEAD". Koseven was created to keep the framework alive and compatible with modern PHP versions. When Koseven was archived on April 14, 2026, Konine was created to continue maintaining and improving the framework for the many applications still running on it.

Are modules from Koseven and Kohana compatible?

Yes they are, just be sure that they are compatible with Kohana 3.3.X. An overview of bundled modules can be found here. There's also a list online with a nice overview of community modules. You can consult this list here.

Security

Is Konine secure?

Konine aims to be a very secure framework with integrated security mechanisms for CSRF, SQL Injections, XSS and many more. Detailed information about this can be found in our Documentation. Security fixes are a primary focus of this actively maintained project.

I found a Security Issue, what now?

We take security seriously. If you find a security vulnerability, please report it via GitHub Security Advisories and we will try to fix it as soon as possible.

Found a Bug?

If you've stumbled across a bug, please help us out by reporting what you have found. Simply visit our GitHub Issue page and submit your issue. Thanks a lot!

Support

Where can I get support for Konine?

You need help, how-to's, guides? A good first place to look is the Koseven GitHub Discussions archive — many common questions have already been answered there. For new questions, please use Konine GitHub Discussions.
